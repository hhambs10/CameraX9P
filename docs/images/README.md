# Screenshot credits

The visible controls are rendered by CameraX9P. A temporary demonstration build displays a generated image in the viewfinder so the screenshots contain no phone camera photos. The release APK and the public source contain neither the demonstration changes nor the viewfinder assets.

The photo preview shows a fictional alpine lake. The video preview and profile menu show a fictional coastal road. The scenes were created with the built-in ImageGen tool using these prompts:

> Use case photorealistic-natural. Generate an original landscape photograph for a synthetic camera viewfinder in a GitHub software demo. Portrait 3:4 composition. An unoccupied red wooden canoe on a still emerald alpine lake, reflections of dark spruce, wisps of low fog halfway up the mountains, clean pale overcast dawn light. Frame the canoe in the center third and keep the foreground calm. Realistic natural color and lens detail. Full bleed photograph only, no text, interface, grid, phone hardware, logos, or people. Entire scene invented.

> Use case photorealistic-natural. Generate a full-bleed wide landscape photograph for a camera application's synthetic video viewfinder. Cinematic blue hour on a wet, winding coastal road beside rocky cliffs and the sea. A small unbranded silver car rounds the curve in the middle distance, restrained headlight reflections, mountain silhouettes and textured storm clouds. Natural realistic photographic light and rich blue shadows, broad 16:9-friendly composition. No phone, overlays, border, text, people, or watermark. Entirely invented scene.
